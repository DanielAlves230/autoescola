# 🚗 Ella Auto

### Autoescola feminina — confiança, acolhimento e liberdade ao volante

Uma landing page moderna e responsiva criada para apresentar os serviços de uma autoescola voltada ao público feminino.

</div>

## Sobre o projeto

O **Ella Auto** é um projeto front-end desenvolvido para oferecer uma experiência visual acolhedora e profissional. A página reúne informações importantes da autoescola em uma interface elegante, responsiva e fácil de navegar.

O projeto foi construído em um único arquivo HTML, reunindo estrutura, estilos e interações para facilitar a visualização e a execução.

## Funcionalidades

- Layout moderno e totalmente responsivo
- Navegação suave entre as seções
- Apresentação dos serviços da autoescola
- Chamadas para ação em pontos estratégicos
- Animações e efeitos visuais
- Menu adaptado para dispositivos móveis
- Identidade visual personalizada

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Como executar

1. Clone este repositório:

```bash
git clone https://github.com/DanielAlves230/autoescola.git
```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code.

## Estrutura

```text
autoescola/

```
